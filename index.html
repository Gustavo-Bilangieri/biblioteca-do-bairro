        06 · Corrigir o código

        O código do enunciado tinha quatro problemas:

        1. getItem("leitura") devolve texto, não um array — tem de levar JSON.parse.
        2. setItem("leitura", lista) guarda [object Object] — tem de levar JSON.stringify.
        3. if (tema == true) nunca é verdadeiro: o valor guardado é o texto "escuro".
        4. dados.nome rebenta quando ainda não há leitor guardado, porque o JSON.parse(null) dá null.
        const lista = ler("biblioteca:leitura", []);        // 1
lista.push("Os Lusíadas");
guardar("biblioteca:leitura", lista);                // 2

const tema = localStorage.getItem("biblioteca:tema");
if (tema === "escuro") document.body.classList.add("escuro");   // 3

const dados = ler("biblioteca:leitor", null);        // 4

        01, 02, 04 e 12 · Respostas

        01 · Espreitar o armazenamento. No separador Aplicação aparecem as chaves do site (por exemplo biblioteca:tema, biblioteca:leitura). localStorage.length diz quantas são e cada site só vê as suas. Os cookies ficam na mesma secção, em «Cookies».

        02 · Onde guardavas? Tema escuro → localStorage (preferência pequena e permanente). Sessão de login → cookie HttpOnly (o servidor precisa dela e o JavaScript não a deve ler). Passo de um formulário → sessionStorage (só neste separador). Mil capas offline → IndexedDB (ficheiros e muito espaço). Reservas → servidor (são partilhadas por todos).

        04 · Prevê o resultado.

        localStorage.getItem("n")              // "20"  (a chave é substituída e vem sempre texto)
localStorage.getItem("n") + 5          // "205" (concatena, não soma)
Boolean(localStorage.getItem("ativo")) // true  (o texto "false" é verdadeiro)
localStorage.getItem("Ativo")          // null  (as chaves distinguem maiúsculas)
localStorage.length                    // 2     ("n" e "ativo")

        12 · Auditoria de privacidade. tema → aceitável (preferência inofensiva). token → a evitar: qualquer script o lê e um XSS leva-o; usar cookie HttpOnly. leitor com NIF → arriscado: guardar só o nome e deixar o resto no servidor. desconto → a evitar: o utilizador edita o valor, o servidor é que decide. passo em sessionStorage → aceitável, é temporário. palavraPasse → nunca.
